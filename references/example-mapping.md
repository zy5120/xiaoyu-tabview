# 页面映射示例（来自鱼律 App 的真实实现）

## 长条按钮 = 原右上角主操作

| 页面 | 原右上角 | 长条按钮 | 行为 |
|---|---|---|---|
| 案件列表 | + | 新建案件 | 菜单：民事 / 刑事 / 行政（顺序与旧版一致） |
| 案件详情·基本信息 | 编辑 | 编辑案件 | 打开编辑页 |
| 案件详情·时间线 | + | 添加时间线 | 菜单：案件节点 / 待办事项 / 时间线节点 |
| 案件详情·文件 | 关联文件 | 关联文件 | 弹出已归档文书列表并关联本案 |
| 待办列表 | + | 新建待办 | 菜单：案件待办 / 我的待办 |
| 委托人管理 | + | 新增委托人 | 进入新建页 |
| 新建委托人（表单） | 保存 | 保存 | 必填缺失时置灰 |
| 送达文书下载 | + | 新增文书下载 | 焦点移到案号输入框 |
| 归档文书详情 | 分享 | 打包分享 | 导出归档 |
| 限高/失信查询（表单） | 查询 | 限高/失信查询 | 焦点移到身份证号输入框 |
| 更多首页 | （无主操作） | 问候语 | 早上好/中午好/下午好/晚上好/深夜好（装饰） |

## 搜索上下文

| 页面 | 搜索上下文 | 提示文字 |
|---|---|---|
| 案件列表 | 案件 | 搜索案件名称 |
| 案件详情·基本信息 | 该案件字段 | 搜索字段名称或内容 |
| 案件详情·时间线 | 该案件时间线 | 搜索时间线内容 |
| 案件详情·文件 | 该案件已关联文书 | 搜索已关联文书 |
| 待办列表 | 待办 | 待办内容 / 关联案件 |
| 委托人管理 | 委托人 | 搜索委托人 |
| 送达文书 | 归档文书 | 案号 / 法院 |
| 更多首页 | 设置项（含子级，点击跳转） | 搜索设置项 |
| 表单页（新建/编辑等） | 隐藏搜索 | — |

## 实现结构要点（鱼律）

- 状态对象：`SearchContextState`（`current` 上下文、`searchText` 共享文本、`focusToken` 焦点令牌、`closeToken` 关闭令牌）。
- 搜索标签内容：`NavigationStack { 按上下文切换的内容 }.searchable(text: $searchContext.searchText, prompt: 按上下文)` —— 搜索框只注册一次。
- 上下文登记：各页面 `onAppear` 设置 `current`：案件列表 `resetToCases()`、案件详情 `setDetail(案件, tab)`、待办 `.todos`、委托人 `.clients`、文书 `.docs`、更多首页 `.more`。
- 长条按钮由“当前主标签 + 页面状态”共同决定；搜索态时 `effectiveTab = lastMainTab`，保留进入搜索前的按钮。
- 搜索结果显示后 `requestClose()` → 切回 `lastMainTab`。

## 反例（踩过的坑）

- 限高/失信查询表单页把搜索上下文登记为“案件搜索”——表单页应隐藏搜索，而不是搜无关列表。
- 更多里的子页面（偏好设置、备份、AI 配置、模板）未登记上下文时会残留“更多首页”的设置搜索——每个子页都要登记自己的类型，纯操作表单页隐藏搜索。
