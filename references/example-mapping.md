# 页面类型 → 长条按钮 / 搜索 通用映射

## 使用方式

1. 先扫描目标 App 的页面结构（标签页、导航栈、各入口），列出全部页面。
2. 把每个页面归类到下面的通用类型。
3. 按映射表确定该页的长条按钮与搜索行为。
4. **无法确定的页面**：把「页面 + 候选行为」列成清单交给开发者选择，不要替开发者擅自决定。

## 通用页面类型映射

| 页面类型 | 典型特征 | 长条按钮 | 搜索 |
|---|---|---|---|
| 列表页 | 展示一类数据（记录 / 条目 / 联系人…） | 新建该列表条目；有多个新建方式时用菜单，选项顺序与旧版一致 | 搜该列表数据 |
| 详情页 | 查看单个对象（基本信息 + 多个子标签） | 编辑 | 搜该对象内部内容（字段 / 子列表） |
| 详情页·子列表标签 | 时间线 / 附件 / 关联项等子内容 | 添加子项（时间线节点 / 关联文件…） | 搜该子列表内容 |
| 只读归档详情 | 查看 / 下载归档内容 | 分享 / 导出 / 打包 | 搜该归档内容 |
| 表单页（新建 / 编辑） | 录入或修改数据 | 保存 / 提交（必填缺失时置灰） | 点击搜索无反应 |
| 查询表单页 | 输入条件后执行查询 | 执行查询（焦点移到首个输入框） | 点击搜索无反应（不注册任何列表上下文） |
| 主入口页（首页 / 更多 / 设置中心） | 导航枢纽，无单一主操作 | 无主操作时放问候语或高频入口 | 搜全部入口 / 设置项（含子级） |
| 设置 / 配置子页 | 一组可改的选项 | 保存 / 无 | 搜该页配置项 |

## 兜底原则

- **长条按钮以旧版右上角主操作为准**：能确认旧版右上角按钮的页面直接照搬；新版开启后右上角不重复显示（非主操作图标如删除可保留在右上角）。
- 多个候选主操作时：列给开发者选择。
- 页面形式无法确认时：把页面清单与候选行为列给开发者，不要猜测。
- 搜索只搜“当前页面正在展示的数据”；纯表单页点击搜索一律无反应（搜索标签无法隐藏，但选中时直接重定向回原页），不要硬搜无关内容。

## 常见错误（反例）

- 查询表单页把搜索登记成“搜列表数据”——查询页应点击无反应，而不是搜无关列表（曾犯过注册成 `.cases` 的错）。
- 子页面（设置、配置、工具页）未登记搜索上下文，残留上一页的搜索——每个子页都要按映射表登记自己的类型，纯操作页点击搜索无反应。
- 用 `id()` 重建搜索标签内容——会反复触发系统“首次激活搜索框跑顶部”的 bug，必须保持单一稳定注册。
